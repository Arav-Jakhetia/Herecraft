# Herecraft

Herecraft is a basic Minecraft-inspired 3D voxel game project built with Java, OpenGL, and LWJGL.

- Built a 3D voxel-based world renderer from scratch using Java and OpenGL via the LWJGL framework.
- Implemented voxel world generation with a simple terrain structure and real-time 3D rendering pipeline.
- Gained hands-on experience with OpenGL graphics programming, shader basics, and 3D math.

## Current World

- One chunk only.
- Chunk size: `16 x 16 x 16`.
- Basic blocks: air, grass, dirt, and stone.
- Simple generated terrain, kept intentionally small and beginner-friendly.
